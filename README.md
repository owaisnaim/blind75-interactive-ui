# ALGOQUEST 75 (NeetCode / LeetCode 75 Gamified)

A gamified web application designed to eliminate the boredom of solving the Blind / NeetCode 75, turning rote algorithm memorization into pattern flow intuition.

## 🚀 Key Features

- **The 8 Core Archetypes**: Condenses 75 problems into 8 memorable mental models so you only need to remember 8 flows.
- **The 15-Second Mental Hook**: Every single problem is paired with an intuitive mnemonic trigger and a 4-step execution flow diagram.
- **Boss Raid Mode (Focus Pomodoro)**: Turn problems into a timed Boss Fight (15 / 20 / 25 min) with boss HP bars and phased combat strikes.
- **The Flow Trainer (Pattern Quiz)**: Rapid-fire multiple choice game to train your instant pattern recognition before coding.
- **15-Second Interview Decision Tree**: Interactive cheat sheet to quickly identify which pattern to use in real interviews.
- **RPG Progression & SFX**: Gain XP, level up your rank (Code Initiate -> Grandmaster of the 75 Runes), earn streak flames, and celebrate solves with confetti and custom Web Audio synthesizers!
- **Local Persistence**: Tracks your solved, mastered, and review problems in `localStorage`.

## 🛠️ Quick Start

```bash
# Run the local Vite dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
